# Ícones sugeridos para temas escolares

Os ícones são do Tabler Icons (versão de linha, ~4.900 ícones, licença MIT). Para
buscar outros: `python3 scripts/icones.py "termo"`. A busca aceita português e
também as tags em inglês do Tabler. A galeria fica em https://tabler.io/icons.
